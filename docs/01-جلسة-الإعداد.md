# جلستا الإعداد — دور حمد (مرة واحدة)

كل ما يحتاج هويتك أو بطاقتك أو رقم هاتفك يُنجز في جلستين، وبعدها لا شيء. Claude يرشدك خطوة بخطوة على الشاشة في الجلسة الثانية.

## الجلسة A — الحسابات (من اللابتوب، نحو 45 دقيقة)

### 1) رقم واتساب الأعمال (WhatsApp Cloud API)
- تحتاج **رقم هاتف جديداً غير مستخدم على واتساب** (شريحة جديدة أو رقم ثابت يستقبل مكالمة تحقق).
- ادخل business.facebook.com ← أنشئ حساب Meta Business باسم الرخصة.
- developers.facebook.com ← My Apps ← Create App ← نوع **Business** ← أضف منتج **WhatsApp**.
- في WhatsApp ← API Setup: أضف رقم الهاتف وتحقق منه بالرمز.
- احفظ: **Phone number ID**، و**WhatsApp Business Account ID**.
- أنشئ **رمز وصول دائم**: Business Settings ← System Users ← Add (Admin) ← Generate token بصلاحيات whatsapp_business_messaging وwhatsapp_business_management ← احفظه.
- من App Settings ← Basic: احفظ **App Secret**.
- أكمل **التحقق من النشاط التجاري** (Business Verification) برفع الرخصة؛ بدونه يبقى الحد 250 محادثة يومياً، وهذا يكفي للبداية.
- اسم العرض: «صوّرها».

### 2) حساب الإعلانات
- في Meta Business: Ad Accounts ← Add ← أضف بطاقتك كوسيلة دفع. لا تنشئ حملة الآن؛ Claude يجهّزها.

### 3) Cloudflare
- dash.cloudflare.com ← Sign up ← أكّد البريد. (الحساب نفسه يُستخدم لموقع مستحقاتي.)

### 4) زينة للأعمال (التحصيل)
- حمّل تطبيق Ziina ← Business ← سجّل باسم الرخصة وارفع الرخصة وكشف حساب 3 أشهر.
- بعد التفعيل: Developers ← API Key ← احفظه. (إن تأخر التفعيل، تعمل الخدمة بروابط دفع ثابتة من التطبيق مؤقتاً.)

### 5) اختياري: مفتاح Anthropic API
- console.anthropic.com ← API Keys ← أنشئ مفتاحاً وضع رصيداً 20 دولاراً. يتيح للبوت الرد على الأسئلة الحرة بذكاء (التكلفة نحو 5–15 دولاراً شهرياً).

**ما ترسله لـ Claude بعد الجلسة (عبر الدردشة):** Phone number ID، الرمز الدائم، App Secret، مفتاح زينة (إن وجد)، مفتاح Anthropic (إن وجد). هذه مفاتيح تشغيل، وليست بيانات بنكية.

## الجلسة B — الجهاز (من تطبيق Claude لسطح المكتب على كمبيوتر الـ4090، نحو ساعة، معظمها تنزيل)
1. افتح تطبيق Claude لسطح المكتب على الجهاز وافتح هذه المحادثة.
2. Claude ينفّذ: `npx wrangler login` (تفتح نافذة متصفح تضغط فيها Allow) ← إنشاء D1 وR2 ← وضع الأسرار ← `wrangler deploy` ← تطبيق schema.sql.
3. Claude يشغّل `agent\install.ps1` بالرابط والرمز: ينزّل ComfyUI والنماذج (نحو 25 GB) ويجهّز التشغيل التلقائي.
4. تسجيل الـwebhook في Meta: Callback URL = `https://sawwerha-bot.<subdomain>.workers.dev/webhook` وVerify Token كما وُضع في الأسرار، وتفعيل حقل **messages**.
5. اختبار حقيقي: ترسل صورة منتج من جوالك إلى رقم الخدمة وتستلم 3 صور.
6. نشر صفحة الخدمة على Cloudflare Pages (مجلد web) وربط النطاق.

## بعد الجلستين
- إبقاء الجهاز شغالاً (أو تشغيله يومياً؛ الطلبات تنتظر في الطابور).
- Claude يطلق حملة الإعلانات بميزانية 50 درهماً يومياً من حساب الإعلانات، ويرسل لك تقريراً أسبوعياً على واتساب وفي هذه المحادثة.
- أوامرك على واتساب (من رقمك المسجّل كمالك): `تقرير` · `status` · `paid <رقم الطلب>` · `pause` · `resume`.
