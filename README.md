# صوّرها (Sawwerha) — صور منتجات بالذكاء الاصطناعي لمتاجر الإمارات

نظام آلي بالكامل: إعلان ← واتساب ← بوت ← إنتاج على RTX 4090 ← تسليم ← دفع.

```
web/        صفحة الخدمة (ثابتة، Cloudflare Pages)
bot/        بوت واتساب: Cloudflare Worker + D1 + R2 (WhatsApp Cloud API)
agent/      وكيل الإنتاج على جهاز ويندوز مع RTX 4090 (Python + ComfyUI)
workflows/  سير عمل ComfyUI (خلفية بيضاء، لايف ستايل، ريل)
ads/        نصوص الإعلانات والعروض
docs/       أدلة الإعداد بالعربية (جلسة حمد، تثبيت الجهاز، التشغيل)
```

## تدفق الطلب
1. العميل يضغط إعلان «اضغط للمراسلة» ويرسل صورة منتجه على واتساب.
2. البوت يحفظ الصورة في R2 وينشئ طلب «عيّنة مجانية» في D1.
3. وكيل الإنتاج على الجهاز يسحب الطلب، ينتج 3 صور، ويرفعها.
4. البوت يرسل الصور للعميل مع الباقات ورابط الدفع.
5. بعد الدفع (webhook من زينة أو تأكيد يدوي) ينتج الوكيل الباقة كاملة ويسلّمها.
6. تقرير أسبوعي آلي للمالك.
